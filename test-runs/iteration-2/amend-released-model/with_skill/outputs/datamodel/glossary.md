# Glossary

- **Permit**: official authorisation.
- **File number** (clerks' term; synonym: reference): human-readable number of the permit file. Identifier in the model: `Permit.reference`, labelled "File number" (D-005). The identifier is to be renamed `fileNumber` in the next major version.
- **Applicant**: person or organisation that applied for the permit (D-007).
- **Expired**: a granted permit whose validity end has passed. Derived, not a stored status (D-006, C-005).
- **Condition category**: kind of obligation a permit condition imposes: environmental, safety or other (D-008).
- Not used any more: **keywords**, deprecated with CR-7 (D-004).
