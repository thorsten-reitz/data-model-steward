| Station | en | Fixed monitoring site with one or more sampling points. | monitoring station | site (ambiguous) |

| Observation | en | One measured (aggregated) value for a time interval. | measurement, value | |
| Delivery | en | One ObservationCollection document sent by a partner. | observation collection | |
| Validity flag | en | EEA AQD code stating whether a value is valid (1 to 4) or not (-1, -99). | validity | quality flag (ambiguous) |
| Verification flag | en | EEA AQD code: 1 verified, 2 preliminary verified, 3 not verified. | verification | |
