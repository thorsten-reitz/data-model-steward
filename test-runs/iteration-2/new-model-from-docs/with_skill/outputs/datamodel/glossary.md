# Glossary

| Term | Language | Definition | Synonyms | Do not use |
|------|----------|------------|----------|------------|
| Tree | en | Individual street or park tree in the cadastre | Baum (legacy `baum`) | |
| Tree number | en | Human-readable number of a tree, legacy `baum_nr` | Baumnummer | "id" (reserved for the UUID) |
| Inspection | en | Visual check of one tree on one date | Kontrolle, Baumkontrolle | "control" |
| Defect | en | Damage or deficiency found at an inspection | Mangel (legacy `maengel`) | |

| Compensation planting | en | New tree planted to replace a felled tree | Ersatzpflanzung | |
| Vitality class | en | Assessed vitality of the tree (1–5, see Q-001) | Vitalitätsstufe (legacy `vitalitaet`) | |
| Site | en | Park or street segment a tree belongs to | Park / Straße (legacy `park`, `strasse`) | "location" (means coordinates) |
| Location | en | Point position of the trunk | Standort, legacy `x`/`y` | |
| Staff member | en | Department employee acting as inspector or arborist | Kontrolleur, Baumpfleger | |
| Contractor | en | Company executing measures | Firma | |
| Species | en | Entry of the city's species list (botanical name) | Art (legacy `art_lat`) | |
