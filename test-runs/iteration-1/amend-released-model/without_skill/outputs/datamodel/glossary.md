# Glossary

- **Permit**: official authorisation.
- **File number** (`fileNumber`; technical name `reference`): human-readable number under which the
  authority files a permit. Clerks' term (CR-7). Unique per permit.
- **Applicant**: person or organisation that applied for a permit. Unknown for some permits registered
  before CR-7.
- **Expired** (effective status): a granted permit whose validity (validUntil, plus validUntilTime or end of
  day) has passed. Derived, not a value of PermitStatus.
- **Condition category**: classification of a permit condition as environmental, safety or other.
